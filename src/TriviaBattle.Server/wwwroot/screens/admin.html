Import

Adds questions from a .csv or .json file. Categories that don't exist yet are created. Questions that already exist (same text in the same category) are skipped, so re-importing is safe. If any row has a problem, nothing is imported and every problem is listed.

CSV format

Category,Difficulty,Question,A,B,C,D,Correct,MediaUrl,Active
Geography,Easy,What is the capital of France?,London,Paris,Rome,Berlin,B,,yes
Science,Hard,"Which gas, by volume, fills most of the air?",Oxygen,Nitrogen,Argon,Helium,B,,yes

Difficulty: Easy, Medium or Hard. Correct: A-D. MediaUrl and Active are optional (blank = active). Wrap text containing commas in double quotes. Excel: "Save as CSV UTF-8".
